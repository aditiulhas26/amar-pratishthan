AMAR PRATISHTHAN - BASIC WEBSITE

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the folder "Amar_Pratishthan_Website".
3. Double-click index.html.
4. The website will open in Chrome.

IMPORTANT:
- This is a basic static website, so npm/node is NOT required.
- The Documents section opens the supplied PDF documents.
- If you later want a dynamic website with an admin panel/database, this can be upgraded.
